## 00:00 开场（0:00 - 1:30）

【画面】标题卡

> 下单写订单库 / 通知扣库存。/ 两库怎么都成或都不成。/ 分布式事务。

## 01:30 死结（1:30 - 4:30）

【画面】写库→发消息 挂了 → 不一致

> 写库成功发消息前挂 / 库存没扣。/ 先发消息库写失败 / 库存扣订单没。/ 两操作两系统 / 不原子。

【留存锚点】"为什么难原子 / 本地事务管不了发消息 / 评论区扣 12。"

## 04:30 Half（4:30 - 8:00）

【画面】时序：发半消息(不可见)→写库→Commit可见/Rollback删

> 半消息对消费者不可见。/ 本地成 Commit 变可见 / 失败 Rollback 删。/ 可见与否绑定本地结果。

## 08:00 回查（8:00 - 11:00）

【画面】Commit 前崩溃 → Broker 回查

> 写库完发 Commit 前崩 / 半消息悬着。/ Broker 定时回查 / 按订单记录补决定。/ 崩溃也不怕。

## 11:00 实战（11:00 - 14:00）

【画面】下单扣库存最终一致

> 半消息→写库→Commit 库存扣。/ 库失败 Rollback 不扣。/ 崩溃回查补。/ 都动或都不动。

## 14:00 收尾

【画面】总结卡

> 今天：Half + Commit/Rollback + 回查。/
> 明天 Day13 / 消息积压治理。/ 点赞订阅。

【画面】结束卡：Subscribe + 「Day13：积压治理」+ 水印
