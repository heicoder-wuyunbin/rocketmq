## 01:00 打电话（1:00 - 3:30）

【画面】写库→短信→审计→返回 串联

【画面】下单→写库+发消息→返回 / 短信审计各自消费

> 下单只干两件事 / 写库 + 发消息 / 立刻返回。/ 短信审计各自消费 / 互不相识可扩容。

【留存锚点】"同业务为啥两种方式 / 因为能不能丢不一样 / 评论区扣 7。"
