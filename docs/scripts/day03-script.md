## 00:00 开场（0:00 - 1:30）

【画面】标题卡 → 讲师

## 01:30 Push 本质（1:30 - 5:00）

【画面】客户端长轮询拉图

> 名字叫 Push / 其实客户端长轮询拉。/ 你只注册监听器 / "有消息叫我" / 拉取重连均衡框架包了。/ 你只管"拿到后怎么办"。

## 05:00 最小代码（5:00 - 8:00）

【画面】IDE 录屏 QuickConsumerService

> subscribe 订阅 topic / registerMessageListener 写处理 / 返回 CONSUME_SUCCESS / start 后台拉取启动。/ 四行核心。

## 08:00 消费组（8:00 - 11:30）

【画面】同组分摊 / 异组各一份 双图

> 同组多实例 / 队列分摊 / 一条只给一个。/ 不同组 / 各消费一份。/ 同组分摊异组各一份 / 这句背下来。

【留存锚点】"同组分摊还是异组各一份 / 评论区打 分摊。"

## 11:30 返回状态（11:30 - 14:00）

【画面】SUCCESS vs 异常乱返回→假成功跳过

> 返回 SUCCESS / Broker 才推进进度。/ 业务抛异常却返回 SUCCESS / 消息假成功跳过 / 数据丢了。/ 只有真成功才 SUCCESS。
