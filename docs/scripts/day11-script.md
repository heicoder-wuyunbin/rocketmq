## 00:00 开场（0:00 - 1:30）

【画面】标题卡

> 默认一条消费一次。/ 打破假设：/ 同一条可能来多次。/ 不重视就事故。

## 01:30 重试（1:30 - 4:30）

【画面】重试 16 次退避 10s→2h → %RETRY%group

> 返回 RECONSUME_LATER / Broker 重投。/ 默认 16 次退避 10s 到 2h。/ 进 %RETRY%group。

【留存锚点】"默认重试几次 / 16 次退避 / 评论区扣 11。"

## 04:30 死信（4:30 - 7:00）

【画面】16 次失败 → %DLQ%group → 人工

> 16 次还失败 / 进死信 %DLQ%group / 不再自动重试。/ 交人工 不是丢。/ 运维要监控。

## 07:00 幂等（7:00 - 9:30）

【画面】扣款 100 重试三次 → 300

> 重试重发 / 同条来多次。/ 扣款逻辑没防护 / 三次扣 300。/ 幂等=多次=一次。

## 09:30 三板斧（9:30 - 12:30）

【画面】唯一键 / SETNX / 状态机

> 一唯一键去重表 / 二 Redis SETNX / 三业务状态机。/ 常组合：状态机兜底+唯一键防并发。

## 12:30 实战收尾

【画面】扣款先去重

> 扣款首步业务主键去重。/ 重试三次只扣一次。/
> 中级班收官。/ Day12 事务消息。

【画面】结束卡：Subscribe + 「Day12：事务消息」+ 水印
