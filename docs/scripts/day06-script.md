【画面】3 台机器各收全量

> 广播每台收全量。/ 场景：3 台服务器本地缓存刷新。/ 集群只 1 台收到 / 另 2 台过期。

【留存锚点】"广播为什么每台都要 / 因为本地缓存各自刷新 / 评论区扣 6。"

## 06:30 offset 区别（6:30 - 9:00）

【画面】左 Broker 右 本地
